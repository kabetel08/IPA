\subsection{I. Project Overview}\label{i.-project-overview}

This file prepares household-level ACS data from IPUMS for analysis of
housing cost burden and ownership trends in California.

\textbf{Key assumptions:}

\begin{itemize}
\tightlist
\item
  Only the householder (PERNUM == 1) is used to represent
  household-level traits
\item
  Household and person weights are already scaled and applied as
  provided
\item
  ACS uses complex sampling; analysis accounts for clustering using
  \texttt{survey::svydesign}
\item
  Data for 2020 may have quality issues due to COVID-19 disruptions
\item
  Income and housing costs are already CPI-adjusted in
  \_CPIU\_2010variables - Using : Race: Simplified race/ethnicity
  identification {[}of Location of household head{]}
\end{itemize}

  weights were imported already scaled correctly (i.e., the implied
  decimals have already been applied). So we will not

\subsubsection{B. Set Up Survey Designs}\label{b.-set-up-survey-designs}

\begin{itemize}
\item
  The ACS data isn't collected randomly --- it uses a complex design
  where some types of households are more likely to be selected than
  others, and households are grouped (clustered) by geography.
\item
  If we ignore this, our results might look more precise than they
  really are (i.e., too small standard errors).
\item
  Using svydesign() helps R understand how the data was collected so it
  can:

  \begin{itemize}
  \tightlist
  \item
    Properly apply the weights (so each household counts for the right
    number of people),
  \item
    Adjust for clustering (so confidence intervals and p-values are more
    realistic).
  \end{itemize}
\item
  We want to use this design for:

  \begin{itemize}
  \tightlist
  \item
    Calculating means or proportions with standard errors
  \item
    Plotting trends with confidence intervals
  \item
    Running regressions or hypothesis tests
  \end{itemize}
\item
  CLUSTER: Household cluster for variance estimation
\end{itemize}
